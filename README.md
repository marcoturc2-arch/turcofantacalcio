# TurcoFantacalcio

Versione web statica pronta per GitHub Pages.

## Pubblicazione
1. Carica `index.html` nella root del repository GitHub.
2. Vai in **Settings > Pages**.
3. In **Build and deployment**, scegli **Deploy from a branch**.
4. Seleziona `main` e `/ (root)`.
5. Salva.

GitHub pubblicherà l'app all'indirizzo Pages del repository.

> Nota: questa versione usa un login lato browser. Non è un sistema di autenticazione sicuro per dati sensibili o accessi reali multiutente.
